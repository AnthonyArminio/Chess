# Chess

This is a long-term personal project designed to practice coding skills, specifically in object-oriented programming and problem solving.
The application features a from-scratch implementation of a chess-playing agent and interface.

# Run the Program

To run the program, clone the repository and run the following commands in the home directory (assuming Java & Maven are installed).

```
chmod u+x run.sh
```
```
./run.sh
```

The Maven dependencies (these can also be found in `pom.xml`):

```
<dependency>
    <groupId>org.openjfx</groupId>
    <artifactId>javafx-controls</artifactId>
    <version>26.0.2</version>
</dependency>

<dependency>
    <groupId>com.google.code.gson</groupId>
    <artifactId>gson</artifactId>
    <version>2.14.0</version>
</dependency>
```
